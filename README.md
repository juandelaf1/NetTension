# NetTension

EU telecom network stress simulation validating 5/6 hypotheses on market dynamics.

[Full Case Study](https://juandelaf1.github.io/projects/net-tension)

## Overview

NetTension simulates competitive dynamics in EU telecom markets under demand and regulatory stress scenarios. Built on public CNMC data, it tests six hypotheses about market concentration, pricing power, and infrastructure investment.

## Key Results

- **5/6 hypotheses** confirmed through data analysis
- **+127% traffic CAGR** vs -0.4% revenue CAGR (price compression)
- **2 public data sources** (CNMC, European Commission)
- **Interactive Power BI dashboard** for scenario exploration

## Stack

Python - Pandas - DuckDB - Power BI - Docker - CNMC Data

## Limitations

- Simulation scenarios are illustrative, not predictive of market outcomes
- Limited to Spanish telecom market data (CNMC)
- Does not incorporate regulatory policy changes or merger effects
